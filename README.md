# Cui Bono? — бот заметок для Telegram

Каждый день бот выпускает 10 заметок (по Москве днём 08:37, 10:37, 12:37, 14:37, 17:07, 19:37, 22:07 и ночью 23:37, 02:37, 05:37), а между ними — рубрики: пн Показатели, вт и чт Позиция, ср, пт и вс Разбор, сб Неделя. Каждая заметка проходит так:

1. **Тема.** Бот читает RSS-ленты изданий (Интерфакс, ТАСС, РБК, «Коммерсант», «Ведомости», «Медуза», The Bell, The Moscow Times, Forbes, Frank Media) за последние 48 часов. Gemini выбирает три лучшие темы, которых не было в ленте за неделю, бот скачивает тексты статей.
2. **Текст.** Gemini пишет заметку только по этим текстам по правилам «Колоды оптик»: рубрика и флай, заголовок одной из десяти форм, подзаголовок, 2–3 абзаца, сухой финал. Ссылки вшиты в цифры.
3. **Валидация.** Код проверяет длину (лимит подписи к фото — 1024 знака), запрещённые обороты, рубрику и форму, и главное — что каждая ссылка ведёт на одну из скачанных статей.
4. **Фактчек.** Отдельный проход Gemini сверяет каждую цифру с текстами статей. Он может пропустить заметку, исправить её или отклонить, тогда бот берёт следующую тему.
5. **Обложка.** Фирменный стиль из брендбука (`bot/brand.py`): тёмный фон #0B0D10, слоновая кость, графит, холодный серый, зелёный #2368AE одним акцентом; Newsreader (словесный знак «Cui Bono?»), Commissioner (заголовки), Onest, IBM Plex Mono (лежат в `assets/fonts`). Справа — ночной снимок Земли NASA (VIIRS Black Marble) и контуры стран вокруг места события, перекрестие и координаты внизу; у события без места — точечная сетка. Если заметка держится на одной цифре — обложка с большой цифрой. «Позиция» — единственная светлая обложка.
6. **Пост.** Фото с подписью уходит в канал. Тема, рубрика, форма и оптики записываются в `state/posted.json`, чтобы соседние заметки не повторялись.

Если ни одна из трёх тем не прошла проверку, в этот слот ничего не публикуется, а GitHub присылает письмо о неудачном запуске.

## Рубрики

Кроме заметок бот ведёт четыре рубрики (отдельный запуск «Cui Bono — рубрики»):

| День, время МСК | Рубрика | Что это |
| --- | --- | --- |
| пн 10:52 | Показатели | Табло цифр недели: курсы, ставка ЦБ, золото — напрямую у ЦБ, индекс — у Мосбиржи; инфляция и нефть — из новостей со ссылкой; «цифра недели» с пояснением; обложка-табло |
| вт и чт 13:52 | Позиция | Передовица: строка «ПОЗИЦИЯ · Мнение редакции», заголовок-вердикт, ровно три абзаца; светлая обложка |
| ср, пт и вс 11:22 (запасной 15:22) | Разбор | Статья на telegra.ph, пишется по частям сильной моделью; в канале — «РАЗБОР · N минут чтения», анонс и кнопка «Читать разбор»; обложка со светящейся плашкой и картой |
| сб 12:52 | Неделя | Как «The world this week»: без заголовка, 6 событий, каждое начинается с жирного «кто/где.»; обложка-оглавление |

Каждая рубрика проходит ту же проверку ссылок и фактчек, что и заметки. Вручную: Actions → «Cui Bono — рубрики» → Run workflow → выбрать рубрику.

## Как запустить (минут 20)

### 1. Бот в Telegram
1. Напишите [@BotFather](https://t.me/BotFather) → `/newbot` → получите **токен**.
2. Добавьте бота в канал администратором с правом «Публикация сообщений».
3. Адрес канала: для публичного — `@имя_канала`. Для закрытого — числовой id вида `-100…`.

### 2. Ключ Gemini API (бесплатно)
Ключ из [Google AI Studio](https://aistudio.google.com/apikey). Бесплатный тариф: деньги не списываются, но Google может использовать запросы для улучшения своих моделей, а веб-поиска на бесплатном тарифе нет — поэтому бот берёт новости из RSS.

### 3. Репозиторий на GitHub
1. Создайте **приватный** репозиторий и загрузите в него содержимое этого архива (кнопка «Add file → Upload files» или `git push`).
2. **Settings → Secrets and variables → Actions → Secrets**, добавьте:
   - `GEMINI_API_KEY` — ключ из Google AI Studio;
   - `TELEGRAM_BOT_TOKEN` — токен от BotFather;
   - `TELEGRAM_CHANNEL` — `@имя_канала` или `-100…`.
3. Там же во вкладке **Variables** (необязательно):
   - `WRITER_MODELS` — цепочка моделей для текста, через запятую (по умолчанию `gemini-3.8-flash,gemini-3.6-flash,gemini-3.5-flash-lite`);
   - `LIGHT_MODELS` — цепочка для выбора темы и фактчека (по умолчанию `gemini-3.5-flash-lite,gemini-3.1-flash-lite,gemini-3.6-flash`);
   - `NEWS_FEEDS` — свой список RSS-лент через запятую;
   - `SITE_LABEL` — адрес сайта внизу обложки, когда домен появится;
   - `CUSTOM_EMOJI_JSON` — свои эмодзи рубрик, см. ниже.
4. **Settings → Actions → General → Workflow permissions** → «Read and write permissions». Это нужно, чтобы бот записывал журнал ленты.

### 4. Пробный запуск
**Actions → «Cui Bono — заметки» → Run workflow**, галочка «Пробный запуск» включена. Через несколько минут внизу страницы запуска появится артефакт `post-…`: в нём обложка, подпись и JSON заметки. В канал ничего не уходит.

Когда пробная заметка понравится, запустите ещё раз со снятой галочкой — это будет первый настоящий пост. Дальше бот работает по расписанию сам.

Остановить: **Actions → «Cui Bono — заметки» → «…» → Disable workflow**.

## Что настраивается

| Что | Где |
| --- | --- |
| Правила редакции, голос, формы, оптики | `bot/prompts.py` — при правке «Колоды» обновляйте и его |
| Ленты новостей | `bot/news.py` или переменная `NEWS_FEEDS` |
| Модели и их порядок | `bot/gemini.py` или переменные `WRITER_MODELS`, `LIGHT_MODELS` |
| Рубрики и их знаки | `bot/rubrics.py` |
| Запрещённые обороты, лимит длины | `bot/compose.py` |
| Обложки | `bot/render.py` |
| Расписание | `.github/workflows/post.yml`, строки `cron` (время в UTC) |

## Свои эмодзи рубрик
По умолчанию перед рубрикой стоит геометрический знак Unicode (`⌂ СОБСТВЕННОСТЬ`). Чтобы вместо него стояли ваши эмодзи из набора, загрузите набор в Telegram и укажите в `CUSTOM_EMOJI_JSON` их id: `{"property": "5368324170671202286", "russia": "…"}`. Учтите: Bot API разрешает ботам custom emoji только если у бота есть дополнительное имя, купленное на Fragment. Без этого оставьте переменную пустой.

## Сколько стоит и хватит ли квоты
Бесплатно. Текст пишет лучшая бесплатная модель Gemini 3.8 Flash, тему и фактчек делает Flash-Lite. На бесплатном тарифе у 3.8 Flash около 20 запросов в день, у Flash-Lite — около 500 (точные цифры для вашего проекта — на странице лимитов в AI Studio). Обычная заметка тратит 1 запрос 3.8 Flash и 2 запроса Flash-Lite, то есть 10 заметок — около 10 и 20. Если у модели кончится дневная квота, бот сам переключится на следующую в цепочке. Квоты сбрасываются в полночь по тихоокеанскому времени, это 10–11 утра по Москве (зависит от перехода США на зимнее время).

## Проверить локально без API
```
pip install -r requirements.txt && python -m playwright install chromium
python -m bot.main --from-json examples/note-property.json
```
В папке `out/` появятся обложка и подпись.

Шрифты обложек (Prata, PT Serif, IBM Plex Mono) подгружаются с Google Fonts в момент отрисовки.
