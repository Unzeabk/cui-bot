# Cui Bono? — бот заметок для Telegram

Каждый день бот выпускает 10 заметок (по Москве днём 08:37, 10:37, 12:37, 14:37, 17:07, 19:37, 22:07 и ночью 23:37, 02:37, 05:37), а между ними — рубрики: пн Показатели, вт и чт Позиция, ср, пт и вс Разбор, сб Неделя. Каждая заметка проходит так:

1. **Тема.** Бот читает 92 RSS-ленты и 8 публичных Telegram-каналов за последние 48 часов (неделю для рубрик). Россия: ленты и деловая пресса, первоисточники (ЦБ, правительство, «Российская газета» и «Парламентская газета» с текстами законов), регионы (Фонтанка, URA.RU, E1, НГС, Чита, Барнаул), независимые на русском, Re:Russia, постсоветские страны. Мир — только экономические разделы: FT, Bloomberg, WSJ, NYT, Economist по регионам, ЕЦБ и ФРС, судоходство и сырьё, платежи и крипта, Rest of World, Корея, Индия, Залив, Африка, Латинская Америка. Каналы (`TG_CHANNELS`) — ЦБ, Минфин и каналы со своими расчётами; бот читает их открытую страницу t.me/s/ без ключей. В отбор идёт до 420 новостей, места раздаются по кругу — по одной самой свежей с каждой ленты, потом по второй (не больше 15 с ленты), чтобы частые ленты не вытесняли мир и регионы. Отчёт о свежести каждой ленты — `feeds.txt` в архиве запуска; мёртвые ленты заменять по нему. Flash-Lite выбирает пять тем про разное с учётом баланса рубрик и для каждой отмечает, в России ли событие и кто главный участник. Код выбрасывает тему, если российская рубрика (Россия, Регионы, Бюджет, Собственность, Оборонная экономика, Экономика, Труд, Регулирование) взята не про Россию, если в «Расчётах», «Санкциях» или «Россиянах за рубежом» нет России, или если тот же участник (Binance, OpenAI…) уже был за трое суток. Писатель рубрику не меняет, фактчек ещё раз сверяет её с материалами; новость, уже бывшая источником, или тема, похожая на заметку за 7 дней, до отбора не доходит. Бот скачивает тексты статей.
2. **Текст.** Gemini пишет заметку только по этим текстам. Правила модель читает целиком из двух файлов: `system.md` (свод издания) и `telegram.md` (поправки формата канала) — `bot/prompts.py` склеивает их и добавляет только технику: поля JSON, ссылки, место для карты. Заодно модель указывает место события для карты на обложке.
3. **Валидация.** Код проверяет длину (950 знаков), запрещённые обороты, рубрику и форму, и главное — что каждая ссылка ведёт на одну из скачанных статей. Кроме того: заголовок 6–9 слов и не больше одной запятой, флай 2–5 слов и не повторяется в тексте, 2–3 абзаца, две оптики из разных семейств и ни одного названия оптики в тексте, без эмодзи, не больше двух цифр в предложении, пример из свода в шапке — не чаще раза в неделю, флай не повторяется 7 дней. По ленте: форма, раскладка и главная оптика не повторяют прошлую заметку, «невозможный факт» — раз в сутки, за неделю не меньше четырёх семейств главных оптик.
4. **Фактчек.** Отдельный проход Gemini сверяет каждую цифру с текстами статей. Он может пропустить заметку, исправить её или отклонить, тогда бот берёт следующую тему.
5. **Обложка.** Фирменный стиль из брендбука (`bot/brand.py`): тёмный фон #0B0D10, слоновая кость, графит, холодный серый, акцент «кратер» — короткий переход от #262B31 к #2F343C, без свечения; Newsreader (словесный знак «Cui Bono?»), Commissioner (заголовки), Onest, IBM Plex Mono (лежат в `assets/fonts`). Справа — ночной снимок Земли NASA (VIIRS Black Marble) и контуры стран вокруг места события, перекрестие и координаты внизу; у события без места — точечная сетка. Если заметка держится на одной цифре — обложка с большой цифрой. «Позиция» — единственная светлая обложка.
6. **Пост.** Фото с подписью уходит в канал. Тема, рубрика, форма и оптики записываются в `state/posted.json`, чтобы соседние заметки не повторялись.

Если ни одна из трёх тем не прошла проверку, в этот слот ничего не публикуется, а GitHub присылает письмо о неудачном запуске.

## Рубрики

Кроме заметок бот ведёт четыре рубрики (отдельный запуск «Cui Bono — рубрики»):

| День, время МСК | Рубрика | Что это |
| --- | --- | --- |
| пн 10:52 | Показатели | Табло цифр недели: курсы, ставка ЦБ, золото — напрямую у ЦБ, индекс — у Мосбиржи; инфляция и нефть — из новостей со ссылкой; «цифра недели» с пояснением; обложка-табло |
| вт и чт 13:52 | Позиция | Передовица: строка «ПОЗИЦИЯ · Мнение редакции», заголовок-вердикт, ровно три абзаца; светлая обложка |
| ср, пт и вс 11:22 (запасной 15:22) | Разбор | Статья на telegra.ph, пишется по частям сильной моделью; в канале — «РАЗБОР · N минут чтения», анонс и кнопка «Читать разбор»; тёмная плашка со светлыми буквами и карта |
| сб 12:52 | Неделя | Как «The world this week»: без заголовка, 6 событий, каждое начинается с жирного «кто/где.»; обложка-оглавление |

Каждая рубрика проходит ту же проверку ссылок и фактчек, что и заметки. Вручную: Actions → «Cui Bono — рубрики» → Run workflow → выбрать рубрику.

«Разбор» пишется по частям: сначала план из пяти частей (в них разложены семь ходов драматургии), потом каждая часть отдельным запросом по 230–320 слов. Пишут только сильные модели (3.8 Flash, затем 3.6 Flash); если у них кончилась квота, разбор откладывается без ошибки, запасной запуск в 15:22 пропускается, если первый вышел.

**Тестовый запуск без квоты:** Actions → «Cui Bono — рубрики» → рубрика, галочка «Тестовый текст» и свой Telegram ID в поле «Куда отправить» (сначала `/start` боту). Бот берёт готовый текст из `examples/<рубрика>-test.json` и в журнал ленты не пишет.

## Как запустить (минут 20)

### 1. Бот в Telegram
1. Напишите [@BotFather](https://t.me/BotFather) → `/newbot` → получите **токен**.
2. Добавьте бота в канал администратором с правом «Публикация сообщений».
3. Адрес канала: для публичного — `@имя_канала`. Для закрытого — числовой id вида `-100…`.

### 2. Ключ Gemini API (бесплатно)
Ключ из [Google AI Studio](https://aistudio.google.com/apikey). Бесплатный тариф: деньги не списываются, но Google может использовать запросы для улучшения своих моделей, а веб-поиска на бесплатном тарифе нет — поэтому бот берёт новости из RSS.

### 3. Репозиторий на GitHub
1. Создайте **приватный** репозиторий и загрузите в него содержимое этого архива (кнопка «Add file → Upload files» или `git push`).
2. **Settings → Secrets and variables → Actions → Secrets**: все ключи — в одном секрете `CUI_CONFIG`, строками `ИМЯ=значение`:
   - `GEMINI_API_KEY` — ключ из Google AI Studio;
   - `TELEGRAM_BOT_TOKEN` — токен от BotFather;
   - `TELEGRAM_CHANNEL` — `@имя_канала` или `-100…`.

   Если токен или ключ где-то засветились — `/revoke` в BotFather, новый ключ в AI Studio, заменить в `CUI_CONFIG`.
3. Там же во вкладке **Variables** (необязательно):
   - `WRITER_MODELS` — цепочка моделей для текста, через запятую (по умолчанию `gemini-3.8-flash,gemini-3.6-flash,gemini-3.5-flash-lite`);
   - `LIGHT_MODELS` — цепочка для выбора темы и фактчека (по умолчанию `gemini-3.5-flash-lite,gemini-3.1-flash-lite,gemini-3.6-flash`);
   - `NEWS_FEEDS` — свой список RSS-лент через запятую;
   - `TG_CHANNELS` — свой список Telegram-каналов через запятую, без @ («-» — без каналов);
   - `SITE_LABEL` — адрес сайта внизу обложки, когда домен появится;
   - `CUSTOM_EMOJI_JSON` — свои эмодзи рубрик, см. ниже.
4. **Settings → Actions → General → Workflow permissions** → «Read and write permissions». Это нужно, чтобы бот записывал журнал ленты.

### 4. Пробный запуск
**Actions → «Cui Bono — заметки» → Run workflow**, галочка «Пробный запуск» включена. Через несколько минут внизу страницы запуска появится артефакт `post-…`: в нём обложка, подпись и JSON заметки. В канал ничего не уходит.

Когда пробная заметка понравится, запустите ещё раз со снятой галочкой — это будет первый настоящий пост. Дальше бот работает по расписанию сам.

Остановить: **Actions → «Cui Bono — заметки» → «…» → Disable workflow**.

## Что настраивается

| Что | Где |
| --- | --- |
| **Правила издания** | `system.md` — копия документа «Cui Bono? — единая система» (https://claude.ai/artifact/YV6JnUWBRQxbzjjubaeYwu). Модель читает файл целиком |
| **Поправки для канала** | `telegram.md` — копия документа «Cui Bono? — Telegram» (https://claude.ai/artifact/R9VCJTQiuChyCJV1f6HaNP). Модель читает файл целиком |
| Как правки доходят до модели | Меняем документ → его копию здесь. Промпты (`bot/prompts.py`, `bot/formats.py`, `bot/indicators.py`) правила не пересказывают, только склеивают файлы и добавляют технику |
| Ленты новостей | `bot/news.py` или переменные `NEWS_FEEDS` и `TG_CHANNELS` |
| Модели и их порядок | `bot/gemini.py` или переменные `WRITER_MODELS`, `LIGHT_MODELS` |
| Рубрики и их знаки | `bot/rubrics.py` |
| Запрещённые обороты, лимит длины | `bot/compose.py` |
| Обложки | `bot/render.py` |
| Расписание | `.github/workflows/post.yml`, строки `cron` (время в UTC) |

## Свои эмодзи рубрик
В посте значка рубрики нет: знак рубрики стоит на обложке. Набор из геометрических знаков 100×100 лежит в `assets/emoji/` (для четырёх новых рубрик заметок знаков пока нет) и создаётся одной кнопкой: Actions → «Набор эмодзи Cui Bono?» → ваш Telegram ID (от @userinfobot), перед этим `/start` у бота. Поставить их в пост бот не может: Bot API разрешает ботам custom emoji только с дополнительным именем, купленным на Fragment.

## Сколько стоит и хватит ли квоты
Бесплатно. Текст пишет лучшая бесплатная модель Gemini 3.8 Flash, тему и фактчек делает Flash-Lite. На бесплатном тарифе у 3.8 Flash около 20 запросов в день, у Flash-Lite — около 500 (точные цифры для вашего проекта — на странице лимитов в AI Studio). Обычная заметка тратит 1 запрос 3.8 Flash и 2 запроса Flash-Lite, то есть 10 заметок — около 10 и 20. Если у модели кончится дневная квота, бот сам переключится на следующую в цепочке. Квоты сбрасываются в полночь по тихоокеанскому времени, это 10–11 утра по Москве (зависит от перехода США на зимнее время).

## Проверить локально без API
```
pip install -r requirements.txt && python -m playwright install chromium
python -m bot.main --from-json examples/note-property.json
```
В папке `out/` появятся обложка и подпись.

Шрифты обложек (OFL) и контуры стран лежат в репозитории (`assets/fonts`, `assets/geo`), обложки не зависят от Google Fonts. Ночной снимок Земли NASA берётся при запуске; если NASA не ответило — обложка без него.

## Устойчивость и журнал
При перегрузке Gemini (503) или обрыве связи — два повтора, затем следующая модель; одна неудача не роняет пачку. Если фактчек недоступен, без проверки не публикуем. Журнал ленты — `state/posted.json` (запись повторяется при параллельных коммитах). Ручной запуск берёт код на момент старта; поле «Сколько заметок подряд» — до 8, пауза 90 секунд. GitHub Actions: 2000 бесплатных минут в месяц, ~2–3 минуты на заметку.

## Сайт-зеркало (поисковый трафик в канал)

После каждой заметки, позиции и разбора бот выкладывает страницу на бесплатный сайт (GitHub Pages): заголовок, текст, обложка, sitemap.xml, feed.xml, разметка для поисковиков. Каждая страница ведёт в канал. Код — `bot/site.py`, шаг «Сайт» в обоих workflow.

Включение (один раз):
1. Создать **публичный** репозиторий для сайта, например `Unzeabk/cuibono`. Settings → Pages → Deploy from a branch → `main`, папка `/ (root)`.
2. Создать fine-grained токен с доступом только к этому репозиторию (Contents: Read and write) и положить в секреты cui-bot как `SITE_TOKEN`.
3. В переменные cui-bot (Settings → Secrets and variables → Actions → Variables): `SITE_REPO` = `Unzeabk/cuibono`, `SITE_URL` = `https://unzeabk.github.io/cuibono`.
4. По желанию: `YANDEX_VERIFICATION` и `GOOGLE_VERIFICATION` — коды из Яндекс Вебмастера и Google Search Console; туда же отправить `sitemap.xml`.

Пока `SITE_REPO` не задан, шаг пропускается. Ошибка сайта не мешает публикации в канал.
